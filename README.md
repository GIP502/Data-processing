# Window Starter — Process Builder / Data Labeling / Result

## 실행
ZIP 전체를 압축 해제하고 START-WINDOW.vbs를 더블클릭하세요. Chrome 또는 Edge가 필요합니다. index.html을 직접 열어도 됩니다. 서버·설치·인터넷 연결 없이 실행됩니다.

세 창의 이름·아이콘·배경과 창 열기/닫기/복원 애니메이션을 유지했습니다. Dock의 보라색은 프로세스 설정, 파란색은 데이터 분류, 녹색은 결과 창입니다. ＋는 닫은 창을 다시 엽니다.

## 가장 짧은 사용 순서
1. Process Builder에서 세 단계(파일 나누기 → 데이터 가져오기·계산 → 결과 만들기)을 정하고 저장합니다.
2. Data Labeling 상단에서 저장한 Process를 선택합니다.
3. 여러 Excel 파일을 넣습니다. 정상 파일은 그대로 두고, 확인 필요·미분류·오류 필터로 문제 파일만 검토합니다.
4. 분류나 값을 수정하고 처리하기를 누릅니다.
5. Result에서 통합 결과 또는 파일별 결과를 확인하고 전체/선택 범위를 복사하거나 Excel/CSV로 저장합니다.

## Data Labeling
파일을 입력하면 최대 3개씩 읽어 각 파일을 자동 분석합니다. 파일 하나의 오류가 다른 파일 분석을 멈추지 않습니다. .xlsx / .xls / .xlsm을 지원합니다. 초기 Drop Zone은 입력 뒤 파일 표로 바뀌며 계속 파일을 추가할 수 있습니다.

파일 표의 각 행은 파일 하나입니다. 선택한 Process의 원본 tag와 계산 tag를 열로 표시합니다. 정상 / 확인 필요 / 미분류 / 오류 상태 필터와 파일명 검색을 제공합니다. 제외한 파일도 표에 남고 처리 제외로 표시합니다.

- 분류: 표의 드롭다운 또는 상세 패널에서 직접 지정합니다. 자동 분류로 되돌릴 수 있습니다. 유형을 바꾸면 기존 유형의 수정값은 초기화합니다.
- 값 수정: 단일 셀 tag는 표에서 직접 편집하고 Enter/Tab 또는 다른 곳을 클릭해 적용합니다. 범위·목록은 값을 클릭한 뒤 상세 패널에서 편집합니다. 열은 Tab, 행은 줄바꿈으로 구분하고 '수정 적용'을 누르세요. JSON 2차원 배열도 사용할 수 있습니다.
- 수정된 원본 tag는 강조색과 ✎ 표시로 구분합니다. 관련 계산은 즉시 다시 수행합니다. 잘못 입력한 숫자는 오류 상태가 되며 처리에 사용할 수 없습니다.
- 상세 패널: 파일 정보, 분류 근거, 원본 시트/셀 위치, 추출값, 계산값, 구체적인 오류를 표시합니다. 접거나 다시 열 수 있습니다.
- 빈값·범위 밖 값·Process의 항상 확인 조건은 확인 필요로 표시합니다. 상세 패널에서 '내용을 확인했습니다'를 선택할 수 있습니다. 분류 충돌은 유형을 먼저 지정해야 합니다.
- 선택 삭제, 전체 비우기, 선택 제외, 상세 패널에서 재포함, 전체/파일별 다시 분석, 수정값을 자동값으로 되돌리기를 제공합니다. 다시 분석은 수정값을 유지합니다. '자동값 복원'은 수정값과 수동 분류를 지웁니다.

Process 이름 옆 ☆로 기본 Process를 지정합니다. Process Builder의 저장 목록과 실시간으로 연결됩니다. 선택한 Process가 수정되면 안내하고, 다시 분석 시 새 규칙을 적용합니다. 다른 Process를 선택하면 이전 분류와 수정값을 초기화합니다.

## 처리 전 확인과 Result
Process Builder의 출력 설정에서 검수 후 처리 방식을 정합니다.
- 문제가 있으면 처리 전에 안내(기본): 모든 정상/확인완료 파일은 바로 처리합니다. 남은 문제가 있으면 확인된 파일만 처리하거나, 계산 가능한 확인 필요 파일도 포함할지 선택합니다. 미분류·분류 충돌·계산/읽기 오류는 포함하지 않습니다.
- 모든 파일 확인이 끝나야 처리: 포함 파일의 미분류·오류·확인 필요가 해결되어야 실행합니다.
- 정상 파일만 처리: 정상 파일만 실행하고 나머지는 제외 목록에 기록합니다.

처리 시 현재 Process, 분류, 수정값을 기준으로 계산·출력을 다시 만들고 확정본을 복사해 Result로 전달합니다. 이후 검수 값을 변경해도 기존 Result는 바뀌지 않습니다. 표 출력은 같은 출력 열을 기준으로 이어 붙이며, 지정 위치 출력은 파일별로 확인합니다. 제외 파일과 제외 원인도 기록합니다.

## Result / 결과
왼쪽 ⅔는 확정 결과 표, 오른쪽 ⅓는 선택·복사·저장 설정입니다. 표 출력은 통합 결과가 먼저 보이며 파일별 탭도 있습니다. 지정 위치 출력은 파일별 결과가 먼저 보입니다. 상단에 Process 이름, 처리/제외 수, 완료 시각을 표시합니다.

- 클릭·드래그로 셀/범위를 선택합니다. Shift로 확장하고 행 번호·열 문자로 전체 행/열을 선택합니다. A2:C10처럼 범위를 직접 입력할 수도 있습니다.
- 표에 포커스를 두면 방향키 이동, Shift+방향키 범위 선택, Ctrl+A 전체 선택, Ctrl+C 선택 복사가 가능합니다. 선택이 없으면 Ctrl+C는 현재 결과 전체를 복사합니다.
- 복사 범위를 현재 결과 전체 또는 선택한 범위로 정합니다. Tab/줄바꿈으로 구분한 텍스트라 Excel에 바로 붙여넣을 수 있습니다. 셀 안의 Tab·줄바꿈·따옴표는 인용 처리합니다.
- Excel(.xlsx)은 현재 결과 한 시트, 선택 범위 한 시트 또는 입력 파일마다 별도 시트를 지원합니다. CSV는 현재 결과/선택 범위 한 개를 UTF-8 BOM으로 저장합니다. 파일 이름을 지정할 수 있습니다.
- 표 제목 포함은 복사와 저장에 공통 적용됩니다. 선택이 데이터 행에서 시작하면 선택한 열의 제목만 한 번 붙입니다. 지정 위치 출력에는 제목을 임의로 추가하지 않으며 빈칸·셀 위치를 유지합니다. 선택 범위 저장은 A1부터 배치합니다.
- Process의 출력 항목과 순서를 유지합니다. 파일명·분류·검수 기록은 실제 결과 열에 자동으로 추가하지 않습니다. 처리 기록을 펼치면 제외 파일/원인, 수동 분류와 값 수정, 경고를 확인할 수 있습니다.
- 화면은 200행/50열씩 이동해 전체를 확인합니다. 전체 복사/저장은 현재 페이지를 넘어 모든 결과를 사용합니다. Excel의 시트 한도를 초과하면 명시적 오류를 표시해 잘림을 방지합니다.

저장 위치 선택을 지원하는 브라우저에서는 저장 대화상자를 열고, 지원하지 않거나 로컬 파일에서 허용하지 않으면 브라우저 다운로드로 저장합니다. 다운로드 위치는 브라우저 설정을 따릅니다. 저장 대화상자 취소 시 다운로드를 시작하지 않습니다.

값을 바꾸려면 Data Labeling에서 수정하고 다시 처리하세요. Result는 확정본만 표시합니다. 내부 Result 창을 닫았다 다시 열면 결과와 선택/출력 설정이 유지됩니다.

## Process Builder v3 병합
설정 영역은 왼쪽 ⅔, 실시간 예시 미리보기는 오른쪽 ⅓입니다. 왼쪽 메뉴에서 세 단계를 고르고 중앙에서 편집합니다.

1. 파일 나누기: 파일명 전체 / 구분자로 나눈 N번째 값 / 특정 셀 / 시트명 기준. 포함·미포함·일치·불일치·시작·끝 비교. 시트는 이름 또는 순서로 선택합니다.
2. 데이터 가져오기: 한 셀·가로/세로 한 줄·표 범위를 A1 시작 주소로 지정합니다. 끝은 고정 / 기준 열·행의 마지막 데이터 / 첫 빈 셀 전까지입니다. 같은 단계에서 사칙연산·합계·평균·그대로 복사한 계산 항목을 만듭니다. 검수 기준에서 최솟값·최댓값·항상 확인 여부도 정할 수 있습니다.
3. 결과 만들기: 출력 이름·항목·순서를 정합니다. 한 셀은 반복, 가로/세로 목록은 결과 행으로, 표는 사용할 열 번호를 지정합니다. 특정 셀에 원래 형태로 배치하는 방식은 고급 설정에 있습니다. 검토 후 처리 방식도 여기에서 선택합니다.

초기 예시는 .xlsx 파일을 분류해 Sheet1 B2부터 기준 열 B의 마지막 값까지 읽습니다. '예시 데이터 보기'로 바로 확인할 수 있습니다. 실제 파일에 맞춰 규칙을 정하세요.

기존 v1 Process도 불러올 수 있습니다. 이름·ID·검수 기준·처리 정책을 유지합니다. 예전 빈 끝 위치는 '시트의 끝까지 (기존 설정)'로 유지하여 추출 범위가 줄어들지 않게 했습니다. 수정본 ZIP 전체를 덮어쓰는 대신 필요한 설정 UI/규칙만 병합했으며 기존 데이터 분류·결과·애니메이션·XLS 읽기 기능을 유지했습니다. 병합 내역은 docs/MERGE_V3.md를 참고하세요.

저장된 Process와 기본 Process는 같은 브라우저 프로필의 로컬 저장소에 보관합니다. 원본 파일, 검수 수정값과 처리 결과는 메모리에만 보관하므로 앱을 완전히 종료하면 사라집니다. 내부 창을 닫고 다시 열면 현재 메모리 상태를 유지합니다. 원본 Excel 파일은 변경하지 않습니다.

## 지원 범위와 자산
암호화된 Excel은 오류로 표시합니다. Excel 수식은 저장된 계산값을 읽고 재계산하거나 매크로를 실행하지 않습니다. 날짜는 Excel 원시 값으로 읽을 수 있습니다. 파일당 50MB, 시트당 100,000행/1,000열/200,000셀, tag·파일별 출력은 10,000셀까지 계산합니다. Process Builder 예시 입력은 20개이며 Data Labeling은 파일 수를 20개로 제한하지 않습니다. 총 사용량은 브라우저 메모리에 따라 달라집니다.

첨부 원본 PNG와 분리한 세 아이콘은 assets/branding에 있습니다. 전체 앱 PNG/ICO와 Windows 실행기 아이콘도 유지했습니다. 브라우저 프로세스 자체의 작업 관리자 아이콘은 Chrome/Edge로 표시될 수 있습니다. Windows 작업 관리자 표시는 별도로 검증하지 않았습니다.

Excel 읽기는 공식 SheetJS CE 0.20.3을 assets/vendor/sheetjs에 포함해 오프라인으로 수행합니다. 라이선스와 출처는 해당 폴더의 NOTICE.md 및 LICENSE에 있습니다.

## 검증 및 수정 위치
52개 테스트에서 v1/v2 저장 호환·동적 범위·시트 순서·표 열 선택·추출·계산·수정값·분류 충돌·확인/처리 정책·결과 분리·애니메이션·범위/제목/문자 인용·Excel 왕복·파일명/시트명·Excel 한도를 확인했습니다. Edge에서 실제 xlsx/xls/xlsm, 손상 파일 격리, 값 수정 후 계산, 상태 필터, 저장 Process 연동, 부분 처리와 Result 전달, 범위값 편집, 200개 파일 분석/제외, 분석 중 삭제를 확인했습니다. Result는 실제 클립보드 복사, Excel/CSV 다운로드 후 다시 읽기, 전체/선택/파일별 시트, 405행/55열 페이지 간 선택, 드래그·행/열·키보드 선택, 지정 위치, 재마운트 및 좁은 창을 검증했습니다. 저장 대화상자의 호출·쓰기·취소 계약은 대체 핸들로 검증했으며 Windows 저장 대화상자 자체는 자동 검사하지 않았습니다.
