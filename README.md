# Window Starter — Process Builder

## 실행
ZIP 전체를 압축 해제하고 START-WINDOW.vbs를 더블클릭하세요. Chrome 또는 Edge가 있어야 합니다. index.html을 브라우저에서 직접 열어도 됩니다. 서버·패키지 설치·인터넷 연결 없이 동작합니다.

## 세 창
- 프로세스 설정 · Process Builder: 구현된 첫 번째 창
- 데이터 분류 · Data Labeling: 기존 빈 구획 유지, 이름과 아이콘 적용
- 결과 · Result: 기존 빈 구획 유지, 이름과 아이콘 적용

실행 시 세 창이 열리고 첫 번째 창이 맨 앞에 보입니다. Dock으로 선택·복원하고 ＋로 닫은 기본 창을 다시 엽니다. 창 이동·크기 조절·최소화·최대화·닫기와 물방울 모핑·그림자·드래그 탄성·반동을 유지했습니다.

## 첫 번째 창 사용 순서
상단에서 Process 이름을 입력합니다. 왼쪽 단계 메뉴에서 세 설정 단계를 고르고, 중앙에서 현재 단계를 편집하며, 오른쪽에서 예시 파일의 분류와 결과를 확인합니다.

1. 파일 나누기: 파일명 전체, `_` 같은 문자로 나눈 몇 번째 값, Excel 내부 특정 셀 등을 기준으로 파일 종류를 정합니다. 화면에서는 “모두 맞아야 함 / 하나만 맞아도 됨”처럼 쉬운 표현을 사용합니다. 규칙 밖 파일과 분류 충돌은 Data Labeling에서 확인합니다.
2. 데이터 가져오기: 한 셀, 세로/가로로 이어진 값, 표 범위를 가져옵니다. 시작 위치는 A1 주소로 지정하고, 끝은 직접 지정하거나 마지막 데이터 / 첫 빈 셀 전까지 자동으로 찾게 할 수 있습니다. 같은 화면에서 곱하기·나누기·더하기·빼기·합계·평균 계산값도 만듭니다. 내부 데이터 타입 이름은 기본 화면에 노출하지 않습니다.
3. 결과 만들기: 결과 열 이름과 넣을 데이터를 정합니다. 한 셀 값은 필요한 행마다 반복되고, 행/열 데이터는 순서대로 결과 행을 만듭니다. 표 범위는 사용할 열 번호를 선택합니다. 파일 하나에서 1행 또는 여러 행을 만들 수 있으며, 원본 모양대로 특정 셀에 배치하는 방식은 “고급 설정” 안에 숨겨 둡니다.

초기 규칙은 .xlsx 파일명 분류, Sheet1의 B2부터 마지막 데이터까지를 `값` List로 읽어 Result 한 열로 출력하는 예시입니다. `예시 데이터 보기` 버튼으로 즉시 동작을 확인할 수 있습니다.

## 미리보기와 저장
.xlsx / .xlsm 예시 파일을 클릭 또는 드래그로 여러 개 넣습니다. 파일별 분류 결과에서 확인할 파일을 선택하세요. 설정 변경 후 분류 → 데이터 읽기 → 계산 → 출력 미리보기가 갱신됩니다. 오류가 있으면 오래된 출력을 숨기고 원인을 표시합니다. 예시 파일 원본은 변경하지 않습니다.

Process 저장·불러오기는 브라우저의 로컬 저장소를 사용합니다. 같은 실행 폴더와 브라우저 프로필에서 사용하세요. 예시 파일은 저장하지 않으며 재실행 시 다시 넣습니다. 불러오기·새로 만들기는 현재 편집 설정을 교체하므로 보존할 설정은 먼저 저장하세요. 불완전한 규칙도 초안으로 저장할 수 있습니다.

## 현재 지원 범위
- .xls 구형 형식, 암호화된 파일은 지원하지 않습니다.
- Excel 수식은 파일에 저장된 계산 결과를 읽습니다. 수식을 재계산하거나 매크로를 실행하지 않습니다. 날짜 서식은 Excel의 원시 값으로 읽을 수 있습니다.
- 예시 파일은 20개, 파일당 50MB까지 선택하며 시트당 100,000행·1,000열·200,000셀까지 읽습니다.
- 데이터 추출 / 출력 미리보기는 10,000셀까지 계산합니다. 화면 표는 30행·12열까지 표시합니다.
- 실제 일괄 처리와 Excel·CSV 출력은 두 번째·세 번째 창의 후속 구현 범위입니다.

## 아이콘 자산
assets/branding/window-icons-original.png는 첨부 원본(2172×724)을 그대로 보존합니다. process-builder.png / data-labeling.png / result.png는 문구를 제외한 아이콘을 각각 분리한 투명 PNG입니다. 창 제목줄과 Dock에 사용합니다.

기존 앱의 전체 아이콘 app-icon-original.png(1254×1254 원본)와 app-icon.ico(16~256px)는 유지합니다. Windows 실행기에서 작업 표시줄·바깥 창 아이콘에 사용합니다. 브라우저 프로세스 자체의 작업 관리자 아이콘은 Chrome/Edge 아이콘으로 남을 수 있습니다. 숨겨진 PowerShell 도우미는 바깥 창이 닫힐 때까지 아이콘 핸들을 유지합니다.
